# UC02 Submit and Verify Hazard Report: demo script (owner Bineth)

**Before the demo (once):**
- Server: `cd server && npm run seed -- --reset-demo`, then `npm run dev`. The reset brings back the six PENDING Colombo reports and keeps the 60-place gazetteer and the counter past GR-2481. New reports start at GR-2482 or later.
- Web console: `cd web && VITE_USE_MOCK=false npm run dev`, opened in **two browser profiles** (needed for E3).
- App: `cd app && EXPO_PUBLIC_USE_MOCK=false EXPO_PUBLIC_API_BASE_URL=http://<laptop-LAN-IP>:3000 npx expo start`, on a phone with Expo Go, outdoors or by a window for GPS.
- Demo flags: **none**. UC02's failures come from real conditions: airplane mode, a stopped server, a pin outside Sri Lanka.
